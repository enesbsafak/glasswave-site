# Glasswave website

Support page, privacy policy and a demo playlist for **Glasswave: IPTV Player**, served with GitHub Pages at
https://enesbsafak.github.io/glasswave-site/

The demo playlist (`demo/playlist.m3u`) lists openly licensed test streams (Apple HLS samples, Big Buck Bunny, Sintel, Tears of Steel) so the app can be tried, and reviewed, without an IPTV provider.

Questions and bug reports: open an issue.
